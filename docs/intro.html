LDNN-A*
大语言模型 + 轻量神经网络 + 自适应加权 A* 的混合路径规划器
LLM 候选路径点 DNN 局部几何评估 LSTM 序列评估 三阶段过滤 自适应加权 A*

摘要

A* 是网格地图路径规划的标准算法，但其扩展和存储的节点数量会随地图尺寸与障碍物复杂度迅速增长， 限制了它在资源受限智能体上的使用。近期工作通过让大语言模型（LLM）提出中间路径点、把搜索切分为更短片段来降低开销。 然而 LLM 对空间的推理能力较弱，提出的路径点常出现错位或冗余，导致绕路、甚至比纯 A* 产生更多搜索开销。 本文提出 LDNN-A*：LLM 仅负责提出候选路径点，由轻量神经网络评估器决定保留哪些—— 一个深度神经网络（DNN）评估每个候选点的局部几何，一个长短期记忆网络（LSTM）评估整条路径点序列。 选出的路径点再经三阶段过滤器剪枝，最终由自适应加权 A* 搜索连接。

整体流程

LLM 生成候选路径点 → DNN / LSTM 打分 → 三阶段过滤剪枝 → 自适应加权 A* 连接
1 LLM 提出候选点

DeepSeek 模型根据起点、终点与障碍物布局，在束搜索树中逐层生成 4 个候选路径点，每层保留 Top-3。

2 神经网络打分

DNN 评估「远离前点 + 靠近终点」的局部几何；路径点 ≥4 时，LSTM 再评估整段序列质量。

3 三阶段过滤

去重 → LLM 复审过滤 → 几何转角过滤（>90° 剔除），再直接连通到终点的点做剪枝。

4 自适应加权 A*

根据地图障碍密度 ρ 与起终点距离 D 自适应计算 α、β 权重，分段连接路径点。

两个神经网络评估器

DNN · 局部几何

输入两个特征：AwayFromFormer（远离前点的归一化距离）与 ProximityToGoal（靠近终点的趋势）， 结构为 2 → 20 → 10 → 1（sigmoid），输出单点评分。

LSTM · 序列窗口

当路径上点数 ≥4 时，取最近 4 个点（2×4）作为窗口输入 LSTM(16) → 1（sigmoid）， 判断整段是否「绕路」，与 DNN 评分取几何平均。

两模型权重均为硬编码初始化后微调：DNN 使用 away/proximity 训练集，LSTM 使用窗口训练集。

评估结论

在多种障碍布局的网格地图上，与 A*、LLM-A*、iLLM-A* 对比， LDNN-A* 在多数场景下于节点扩展数与峰值内存上持平或更优，同时路径长度保持在任一方法最短路径的 7% 以内。消融实验表明，路径点过滤是控制搜索开销的主要因素。
