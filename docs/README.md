A* is a standard algorithm for grid-based path planning, but the number of nodes it expands and stores grows rapidly with map size and obstacle complexity, which limits its use on resource-constrained agents. Recent work reduces this overhead by letting large language models (LLMs) propose intermediate waypoints that guide the search. However, LLMs reason poorly about space, so the proposed waypoints are often misplaced or redundant, which causes detours and wastes search effort. We present LDNN-A*, a hybrid planner in which the LLM only proposes candidate waypoints, while lightweight neural evaluators decide which ones to keep. A deep neural network assesses the local geometry of each candidate, and a long short-term memory network assesses its consistency with the recent waypoints. The selected waypoints are then pruned by a three-stage filter and guide an adaptive dual-weighted A* search. We evaluate LDNN-A* on the 1000 test samples of the LLM-A* benchmark against A*, LLM-A*, and iLLM-A*. On average, LDNN-A* reduces the numbers of expanded and stored states to 27.3% and 41.4% of those of A*, the lowest among all methods, while its paths are only 3.9% longer than those of A*. Ablation studies show that waypoint filtering contributes the most.
